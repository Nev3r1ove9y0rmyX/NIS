# 扩展目标 E6 账号与终端 IP/MAC 绑定（2026-11-02）

- 测试人：A
- 环境：本机 SQLite 全栈，`develop @ 1d0bbd0` + 本轮本地实现（未提交）
- 实现：`nis_iam.user_device_bindings`（账号维度，逗号分隔的允许 IP / MAC 列表），登录时校验；网关把客户端真实地址以 `X-Forwarded-For` 透传给 IAM，MAC 由客户端 `X-Device-MAC` 头上报。

## 断言（10 条全部通过）

| 断言 | 结果 |
|---|---|
| 设置 IP 绑定（`enforced=true`） | 200 |
| 非绑定终端登录 | **403 FORBIDDEN** |
| 绑定终端登录 | 200 |
| 增加 MAC 绑定后缺少 MAC 头 | **403** |
| MAC 不匹配 | **403** |
| MAC 匹配 | 200 |
| 非法 IP 格式（`abc`） | **400 INVALID_REQUEST** |
| 解除绑定 | 200，`enforced=false` |
| 解除后任意终端可登录 | 200 |
| 绑定变更写入审计 | 通过（`user.device_binding.update`） |

## 关键实现点

- **IP 真实来源**：网关在转发前写入 `X-Forwarded-For`，IAM 取第一个地址；否则 IAM 只能看到网关自身地址，绑定会把所有终端误判为同一台；
- **MAC 的边界**：浏览器无法读取本机 MAC，当前由客户端在登录请求头中上报、服务端与绑定值比对；能防"换一台机器随手登录"，不防伪造，报告中如实说明"依赖受控内网"；
- **校验位置**：仅登录时校验（符合"只允许绑定设备登录"），不增加每请求开销。
