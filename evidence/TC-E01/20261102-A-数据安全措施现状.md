## 已落实并核对

| 措施 | 核对方式 | 结果 |
|---|---|---|
| 口令自适应哈希 | 查 `nis_iam.users.password_hash` | 8 个账号全部 `$2b$12$` 前缀、长度 60（bcrypt，12 轮），无明文、无可逆加密 |
| 令牌机制 | 登录返回 JWT，业务服务本地验签 | RS256；私钥只在 IAM，其余服务只拿公钥 |
| 审计脱敏 | 查 `audit_events.details` | 97 条事件中提及 `password`/`token` 的记录 **0 条** |
| 数据库账号隔离 | `docs/data-model.md` §12.1 + `deploy/mysql/init/01-databases-and-accounts.sh` | 一 Schema 一运行账号；`nis_audit` 仅 `SELECT/INSERT`（派生表单独 `UPDATE`） |
| 数据库不对外 | `deploy/docker-compose.yml` | 仅映射 80（443 注释保留证书位）；3306 与 8001–8007 不映射 |
| 备份与恢复 | D 的 `deploy/backup/`（`backup.sh` / `restore.sh`） | 交互确认 + `set -euo pipefail`；D 已在本地跑通一次恢复 |

## 结论

“必要的数据安全措施”在**存储、鉴权、审计、访问面**四方面已具备并留证；
**传输加密**是唯一明确缺口。申报时应如实说明边界：受控内网 + 反向代理入口，未启用 TLS。
