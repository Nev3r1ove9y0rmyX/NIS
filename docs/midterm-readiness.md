## 四、现场复验清单（网络四项，D 执行）

```text
1) 三域网段     ipconfig / iKuai 状态页       → 三个不同网段
2) 内网→外网    curl -I https://www.baidu.com  → 200
3) 内网→DMZ     curl -I http://<iKuai-LAN>:80  → 200（映射到 10.1.1.20:8080）
4) 外网→DMZ     curl -I http://<iKuai-WAN>:80  → 200；未映射端口 → 拒绝
5) DMZ→内网     ping / curl 内网终端           → 全部失败，防火墙有命中日志
```

每条命令的输出贴进 `evidence/TC-B0x/`，A 据此把报告对应行改为"通过"。

## 五、申报时的说法（避免被追问）

1. **"多用户"不等于"多终端"**：脚本与冲突测试是同机多账号，现场必须演示四终端；
2. **AI 是规则模板**：如实说明，强调"人在回路"与降级路径已实现；
3. **数据安全不含 HTTPS**：说明传输层依赖受控内网与反向代理，可用自签证书补齐；
4. **未实现的 3 项扩展不写进申报**，在报告"已知限制"里列一句即可。
