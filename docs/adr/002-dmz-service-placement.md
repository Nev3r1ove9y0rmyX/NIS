# ADR-002：API 与中心数据库位于 DMZ 服务侧

状态：已提议，待全组及教师要求确认
日期：2026-10-13

## 背景

基础验收要求外网能访问 DMZ 公开服务，同时要求 DMZ 主机无法访问内网任何主机服务。如果 API 位于 DMZ、数据库位于内网，API 到数据库连接会直接与拒绝测试发生冲突。

## 决策

Web/API 和中心数据库位于 DMZ 服务侧的不同虚拟机或容器。数据库不做外网端口映射，仅允许 API 主机访问数据库端口；DMZ 到信任内网全部拒绝。

## 后果

- 优点：可严格通过 DMZ 到内网拒绝测试，部署路径清晰。
- 代价：数据库位于安全暴露面更高的区域，需要主机隔离、访问白名单、低权限账号、备份和审计。
- 备选：若教师明确允许 DMZ 到内网数据库的单端口例外，再通过新 ADR 调整。
