# ADR-003：AI 为可降级建议服务

状态：已提议，待全组评审
日期：2026-10-13

## 背景

课程要求 AI 赋能 OODA 每个环节并确保人在回路。模型服务可能超时、不可用或产生不可靠结果，不能让它直接推动关键业务状态。

## 决策

四个环节统一采用“请求建议 -> 展示来源 -> 人工接受/修改/拒绝 -> 人工确认 -> 正式提交”的模式。AI 调用和正式业务提交分离；AI 不可用时人工流程继续。

## 后果

- 优点：满足人在回路，可审计、可降级、易于替换模型。
- 代价：需要保存建议来源、确认信息，并在四个工作台提供一致交互。
- 禁止：AI 自动指派用户、自动下达指令或自动提交执行结果。
