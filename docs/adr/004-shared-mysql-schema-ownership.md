# ADR-004：单 MySQL 实例与 Schema 数据所有权

状态：已接受

日期：2026-10-16

## 背景

课程要求部署中心数据库，而 SOA 要求服务拥有清晰数据边界。每个服务独立数据库实例会增加备份、网络、资源和跨服务一致性的实现成本。

## 决策

使用一个 MySQL 8 实例，每个持久化服务拥有独立逻辑 Schema 和独立低权限账号。服务只写自己的 Schema，跨服务数据通过 API 获取，跨服务引用使用 UUID，不建立跨 Schema 外键。

## 后果

- 满足中心数据库要求，同时保留逻辑数据所有权。
- 统一备份和部署，适合单机 Docker Compose。
- MySQL 实例仍是共享故障点，需要健康检查和恢复验证。
- 必须通过账号权限、代码评审和测试阻止跨 Schema 直接写入。
