# ADR-001：采用课程适配型 SOA

状态：已接受

日期：2026-10-16

## 背景

系统需要体现面向服务架构，同时由四人团队在课程周期内完成完整 OODA 闭环、网络隔离和现场验收。完全微服务化会额外引入注册中心、消息中间件、分布式事务和复杂运维。

## 决策

采用课程适配型 SOA：单仓库、统一 API Gateway、8 个粗粒度服务、REST/JSON 契约、Docker Compose 和中心 MySQL。服务可独立构建和部署，但不引入消息队列、服务注册中心和分布式事务作为基础依赖。

## 后果

- 优点：明确体现服务边界、独立部署、契约通信和数据所有权。
- 优点：单机即可完成课程现场部署，控制四人联调成本。
- 代价：需要维护多个服务进程、OpenAPI 契约和跨服务故障处理。
- 限制：首期不追求每个服务完全独立技术栈或独立数据库实例。

## 被替代方案

此前候选的模块化单体方案被本 ADR 取代。若 SOA 实现风险影响 P0 验收，可以通过新 ADR 将部分尚未独立的服务临时合并部署，但接口和数据边界不得消失。
