# ADR-001：采用模块化单体

状态：已提议，待全组评审
日期：2026-10-13

## 背景

四人团队需要在较短课程周期内实现具有统一事务、权限和审计要求的 OODA 闭环。微服务会引入服务发现、分布式事务、跨服务日志和额外部署成本。

## 决策

采用 Vue 前端、FastAPI 模块化单体和 MySQL 中心数据库。后端按 IAM、组织、侦察、分析、决策、执行、AI辅助、审计划分模块，在同一应用内通过服务层协作。

## 后果

- 优点：开发和部署简单，事务与审计一致性更易保证。
- 代价：后端是单一部署单元，需要通过模块边界控制耦合。
- 复审条件：课程范围明显扩大，或单模块需要独立扩缩容时重新评估。
