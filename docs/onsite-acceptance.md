适用环境：A 的电脑（Windows）+ iKuai VM + Ubuntu DMZ VM + B/C/D 三台终端；热点由手机提供。

|---|---|
| 热点网关 | `10.252.150.129` |
| iKuai LAN1 | `10.252.150.10` |
| iKuai LAN2（DMZ 网关） | `192.168.58.2` |
| DMZ 应用主机 | `192.168.58.20` |
| iKuai WAN1 | `192.168.146.10` |
| 外部测试机（A 的 Windows VMnet8） | `192.168.146.1` |

## 一、B/C/D 打不开 `http://192.168.58.20` 的定位三步

终端在热点网段 `10.252.150.0/24`，DMZ 在 `192.168.58.0/24`，**两台不在同一网段**，必须经 iKuai 转发。按顺序测：

### 第 1 步：终端能否到 iKuai LAN1

在 **B 的电脑**（管理员 PowerShell）：

```powershell
ping 10.252.150.10
```

| 结果 | 说明 | 处理 |
|---|---|---|
| 通 | 二层正常，进入第 2 步 | — |
| 不通 | 热点开了客户端隔离，或 iKuai 没桥接到该 Wi-Fi | 换一台手机开热点（关掉"AP 隔离"）；或把 iKuai 网卡改成"桥接：指定无线网卡"后重启 iKuai |

### 第 2 步：终端有没有到 DMZ 的路由

```powershell
route print | findstr 192.168.58
```

| 结果 | 处理 |
|---|---|
| 没有输出 | 需要加路由（第 3 步） |
| 有 `192.168.58.0  255.255.255.0  10.252.150.10` | 跳过到第 4 步 |

### 第 3 步：加路由（必须管理员）

```powershell
route add 192.168.58.0 mask 255.255.255.0 10.252.150.10 -p
ping 192.168.58.20
```

> 报"请求的操作需要提升" = 当前不是管理员：开始菜单搜索 PowerShell → 右键 **以管理员身份运行**。

**替代方案（不想加路由）**：把该终端的 IPv4 改成静态地址，网关直接填 `10.252.150.10`：

```text
IP: 10.252.150.101   掩码: 255.255.255.0   网关: 10.252.150.10   DNS: 223.5.5.5
```

### 第 4 步：能 ping 通但浏览器打不开

| 检查 | 操作 |
|---|---|
| iKuai ACL 顺序 | 安全设置 → ACL 规则：① 阻断 DMZ→内网 ② 允许 内网→DMZ ③ 允许 DMZ→任意；「连接方向匹配」全部 **原始方向** |
| LAN2 是否启动 | 网络设置 → 内外网设置：LAN2 `192.168.58.2` 状态"已连接" |
| 服务是否在跑 | Ubuntu：`docker compose -p nis ps` 应 11 个 healthy |
| 端口是否通 | 终端：`curl.exe -I http://192.168.58.20/`（返回 200 即可） |

## 三、四个角色各登录一次

| 角色 | 账号 | 登录后应看到 |
|---|---|---|
| 侦察员 | `recon01` | 侦察工作台：我的记录、新建侦察、AI 建议按钮 |
| 分析员 | `analyst01` | 分析工作台：待分析报告、AI 辅助 |

## 五、故障树（现场 30 秒定位）

| 现象 | 最可能原因 | 一步处理 |
|---|---|---|
| 终端 ping 不通 iKuai | 热点隔离 / 桥接错网卡 | 换手机热点；iKuai 网卡改"桥接→指定无线网卡" |
| ping 通 iKuai 但 ping 不通 DMZ | 终端没加路由 | 管理员执行 `route add ... -p` |
| ping 通 DMZ 但网页打不开 | 服务挂了 | Ubuntu `docker compose -p nis ps` 看是否 11 healthy |
| 网页能开但一直转圈 | ACL「连接方向匹配」设成了"关闭" | 改成"原始方向" |
| 登录 500 | 数据库表缺失（重建环境时） | 跑迁移 `migrate_all.py --verify` |
| 所有终端显示同一 IP | 网关覆盖了 X-Forwarded-For | 已是修复版；确认 gateway 镜像为最新 |
| 外网口访问不了 | 端口映射没配 | iKuai：WAN1 80 → `192.168.58.20:80` |
