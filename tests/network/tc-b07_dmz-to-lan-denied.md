# TC-B07 DMZ 禁止访问内网

| 项 | 内容 |
|---|---|
| 用例编号 | TC-B07 |
| 关联需求 | NFR-SEC-002（architecture §6）；数据流 DF-05、规则 FW-05 |
| 目的 | 证明 DMZ 主机无法访问信任内网任何主机的任何服务（无例外） |
| 执行人 | D |
| 环境 | srv-dmz-01（10.1.1.20）为源；内网靶标：term-d 10.0.1.104、term-a 10.0.1.101 |
| 前置条件 | [README 通用前置条件](README.md)；term-d 临时启动 echo 服务或确保 ICMP 可作为探针 |

## 步骤

1. 在 srv-dmz-01 执行（ICMP + 常见服务端口逐台探测）：

   ```bash
   ping -c2 -W2 10.0.1.104        # 期望 100% 丢包
   ping -c2 -W2 10.0.1.101
   for t in 10.0.1.101 10.0.1.104; do
     for p in 22 80 135 139 445 3389 8080; do
       nc -z -w2 $t $p && echo "$t:$p OPEN" || echo "$t:$p filtered"
     done
   done
   ```

2. 内网连通性对照（证明探测方法本身有效）：term-d 对 term-a 执行同样探测，
   至少 ICMP 与一个已知开放端口可达；
3. iKuai「防火墙 → 日志」过滤源 `10.1.1.0/24`，截图 FW-05 拒绝命中记录；
4. 反向确认业务不受影响：内网终端仍可正常访问 `http://10.1.1.20/`（TC-B04 已证）。

## 期望

- 步骤 1 所有探测失败（无 OPEN、ping 100% 丢包）；
- 步骤 2 对照探测至少一项成功（排除"探测方法无效"造成的假阴性）；
- 步骤 3 日志出现 FW-05 命中且动作为拒绝。
